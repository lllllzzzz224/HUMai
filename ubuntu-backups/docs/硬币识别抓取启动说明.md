# RM65 硬币识别与首次受限抓取启动说明

## 当前系统参数

- 机械臂：RM65
- 机械臂 IP：`192.168.1.18`
- ROS 2：Jazzy
- YOLO 权重：`/home/li/hand_eye_calibration/best.pt`
- 抓取程序：`/home/li/hand_eye_calibration/coin_grasp.py`
- 配置文件：`/home/li/hand_eye_calibration/coin_grasp_config.yaml`
- 桌面高度：基座坐标系 `z = -0.090 m`
- 夹爪估算长度：`80 mm`
- 运动速度：`5%`

> 当前启用了 `approach_only: true`。机械臂只会到硬币上方约 100 mm
> 的观察位置，然后由程序强制停止；不会继续下降、闭合夹爪或真正抓取。

## 运行前安全检查

1. 机械臂、导轨和夹爪安装牢固。
2. 相机、夹爪和硬币位置没有发生安装变化。
3. 桌面附近及机械臂运动范围内没有人和障碍物。
4. 操作人员站在机械臂范围外，并可以立即按下急停。
5. 硬币放在机械臂可达区域内。
6. RealSense 相机已经连接。
7. 不要同时运行旧的抓取程序或其他机械臂控制程序。

## 终端一：启动RM65真机栈

打开第一个终端：

```bash
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
ros2 launch rm_bringup rm_65_bringup.launch.py
```

保持该终端运行，不要关闭。

启动后会出现 RViz。确认：

- RViz 模型姿态与真机一致；
- 驱动没有持续输出连接错误；
- 机械臂 IP 是 `192.168.1.18`。

## 终端二：检查真机状态

打开第二个终端：

```bash
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
ping -c 3 192.168.1.18
ros2 topic echo --once /rm_driver/udp_joint_pose_euler
```

必须满足：

- `ping` 能收到回复；
- ROS 话题能输出 `position` 和 `euler`；
- 数据不是全零，并且与当前真机姿态大致一致。

如果话题没有输出，不要启动运动，先检查真机栈和网络。

## 终端三：启动YOLO识别与受限运动程序

打开第三个终端：

```bash
cd ~/hand_eye_calibration
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
conda activate yolo11
python coin_grasp.py
```

正常时会打开 RealSense/YOLO 画面。

按键：

- `L`：锁定稳定的硬币目标；
- `E`：进入带逐步确认的受限运动；
- `Q` 或 `Esc`：退出程序。

## 锁定硬币

先等待画面持续显示：

```text
TRACKING dime ...
```

类别也可能显示 `penny`、`nickel` 或 `quarter`，取决于训练结果。

等待采样数量达到要求后按 `L`。终端应显示类似：

```text
Locked coin base point: [0.216, 0.611, -0.086]
Table safety: table safety checks passed
```

并打印 `approach`、`verification` 和 `final` 目标。

必须确认：

- 硬币基座 Z 大约接近 `-0.090 m`；
- 显示 `table safety checks passed`；
- `approach` 坐标在工作空间以内；
- 坐标没有突然跳变。

若显示以下任何内容，不要按 `E`：

```text
base point outside workspace
invalid/insufficient depth
Target unstable
Motion rejected
```

## 首次受限运动

锁定成功后按 `E`。

程序要求输入完整确认口令。只有输入完全一致才会发布命令。

### 1. 打开夹爪

```text
EXECUTE OPEN GRIPPER
```

### 2. 保持当前高度横移

检查终端打印的 `OVERHEAD TRANSIT` 坐标。确认安全后输入：

```text
EXECUTE OVERHEAD TRANSIT
```

机械臂会以 `5%` 速度，在较高位置移动到硬币上方。

完成后先观察：

- 机械臂没有碰到导轨、桌面或相机线缆；
- 夹爪大致位于硬币上方；
- 夹爪保持竖直向下。

### 3. 下降至100 mm观察位置

只有上一步安全时才输入：

```text
EXECUTE APPROACH
```

机械臂会直线下降到硬币上方约 100 mm。随后程序必须显示：

```text
Approach-only safety stop: verification/final/grasp are disabled
```

当前测试到这里结束。不要手动发布其他下降命令。

## 测量和记录

机械臂停在观察位置后，记录：

- 夹爪尖端是否正对硬币中心；
- X 方向偏差（mm）；
- Y 方向偏差（mm）；
- 夹爪尖端到硬币表面的实际垂直距离（mm）。

只有确认这些数据后，才能决定是否开放 30 mm 验证位置。

## 正常停止

识别窗口处于活动状态时按：

```text
Q
```

然后在真机栈终端按：

```text
Ctrl+C
```

## 紧急情况

如果机械臂方向错误、姿态异常、接近障碍物或出现意外运动：

1. 立即按下物理急停；
2. 不要依赖关闭识别窗口来紧急制动；
3. 排除原因前不要重新执行。

## 重新启动

如果识别程序退出但真机栈仍在运行，只需重新执行：

```bash
cd ~/hand_eye_calibration
source /opt/ros/jazzy/setup.bash
source ~/ros2_ws/install/setup.bash
conda activate yolo11
python coin_grasp.py
```

如果真机栈也已关闭，则从“终端一”开始重新执行全部流程。
