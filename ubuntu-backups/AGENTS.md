# Ubuntu 机械臂代码备份约定

## 目录结构

- `snapshots/YYYY-MM-DD/`：按日期保存从 Ubuntu 主机复制的代码快照。
- 每个快照必须包含 `MANIFEST.md`，记录来源主机、原始路径、复制时间和排除项。

## 命名规则

- 目录名保持与 Ubuntu 原项目一致，便于回查来源。
- 位于 Ubuntu 主目录的独立脚本统一放入 `home-probes/`。

## 内容边界

- 快照用于备份与阅读，不作为已经在 Mac 上可运行的证明。
- 保留源码、配置、模型和项目文档。
- 排除 `.git`、构建产物、运行日志、测试缓存和 `__pycache__`。
- 不把密码、SSH 私钥、Shell 历史或用户配置目录复制进来。

## 清理规则

- 不覆盖已有日期快照；同日需要重做时先核对差异并增加时间后缀。
- 不直接修改快照中的源码；需要开发时复制到单独的工作目录。
