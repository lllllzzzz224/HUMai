# 苹果抓取参数配置说明

适用程序：

```text
$APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp.py
```

主要配置文件：

```text
$APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp.yaml
```

本文以 2026-08-10 已真机成功的参数为基线，说明常用参数在哪里修改、修改后影响哪一段，以及哪些参数不能随意调整。

## 1. 最重要的结论

平时需要调整抓取程序时，优先只修改：

```text
single_apple_full_grasp.yaml
```

该 YAML 在每次启动 `single_apple_full_grasp.py` 时重新读取。因此：

- 修改 YAML 后，停止当前抓取程序并重新运行抓取命令即可；
- ROS 2、MoveIt、RealSense 和 RViz 主启动通常不需要重启；
- 如果修改的是 `apple_center_localizer_v2.py` 或启动文件，则需要重启苹果定位节点，最简单是重启完整 launch；
- 修改 YAML 时保留两个空格缩进，不要使用 Tab；
- 距离统一使用米，速度使用米/秒，角度大多使用度或弧度，夹爪开度使用毫米。

推荐先复制成功配置，再改副本：

```bash
cp $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp.yaml \
   $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp_manual.yaml
```

使用副本启动：

```bash
$APPLE_YOLO_PYTHON \
  $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp.py \
  --config $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp_manual.yaml \
  --execute --operator-confirmed --fully-autonomous
```

这样可以保留已经成功的默认配置。

## 2. 机械臂移动速度在哪里改

速度分为两类：

1. `velocity_scaling` / `acceleration_scaling`：相对于机械臂和 MoveIt 限制的比例，范围通常为 0～1；
2. `max_tcp_speed_m_s`：TCP 的实际直线速度上限，单位 m/s。

笛卡尔运动同时受这两类参数限制，实际速度由更严格的一项决定。因此把 TCP 限速调大，不一定会明显加速；缩放值仍可能是限制因素。

### 2.1 关节空间运动速度

配置位置：

```yaml
moveit:
  velocity_scaling: 0.05
  acceleration_scaling: 0.05
```

影响：

- 当前机械臂位置 → SCAN；
- SCAN → PREGRASP；
- PREGRASP → SCAN；
- 其他通过 MoveIt/OMPL 生成的关节空间轨迹。

数值含义：

```text
0.05 = 使用上限的 5%
0.08 = 使用上限的 8%
0.10 = 使用上限的 10%
```

当前真机成功基线是 `0.05 / 0.05`。如果需要加快，建议先试 `0.06` 或 `0.08`，不要一次从 0.05 跳到很高。加速度缩放建议不高于速度缩放。

### 2.2 PREGRASP → VERIFY 接近速度

配置位置：

```yaml
cartesian:
  max_tcp_speed_m_s: 0.010
```

当前含义：

```text
0.010 m/s = 10 mm/s
```

影响：

- PREGRASP → VERIFY；
- 旧的通用笛卡尔测试流程。

这一段还离桌面有 30 mm，当前速度已经很保守。通常可在 `0.008～0.015 m/s` 内小幅调整。

重要：这段真实执行的速度/加速度缩放目前在
`single_apple_full_grasp.py` 中写为：

```python
velocity_scaling=0.05
acceleration_scaling=0.05
```

因此 YAML 中目前只提供该段的 TCP 速度上限，没有单独的接近段缩放字段。

### 2.3 VERIFY → GRASP 最后下降速度

配置位置：

```yaml
grasp_cartesian:
  velocity_scaling: 0.03
  acceleration_scaling: 0.03
  max_tcp_speed_m_s: 0.006
```

当前含义：

```text
0.006 m/s = 6 mm/s
```

影响：

- VERIFY → GRASP 的完整路径预检；
- `max_tcp_speed_m_s` 同时影响真实下降。

这是最接近苹果和桌面的阶段，不建议为了节省几秒明显加速。建议保持在 `0.004～0.008 m/s`。

当前真实执行的缩放值仍在 Python 中写为：

```python
velocity_scaling=0.03
acceleration_scaling=0.03
```

所以修改 YAML 中的 `grasp_cartesian.velocity_scaling` 和
`acceleration_scaling` 会影响预检；真实执行缩放仍是 0.03。YAML 中的
`max_tcp_speed_m_s` 对真实执行有效。

### 2.4 LIFT、放回和撤离速度

配置位置：

```yaml
lift_cartesian:
  velocity_scaling: 0.03
  acceleration_scaling: 0.03
  max_tcp_speed_m_s: 0.010
```

影响：

- GRASP → LIFT；
- LIFT → RELEASE；
- RELEASE → PREGRASP；
- 以上路径的预检和 TCP 速度上限。

当前 `0.010 m/s` 等于 10 mm/s。需要小幅加快时，可先试
`0.012～0.015 m/s`，确认苹果不会晃动或滑落后再决定是否保留。

这些段的真实执行缩放目前同样在 Python 中固定为 `0.03 / 0.03`；
YAML 中的 TCP 速度上限会生效。

### 2.5 当前速度配置的实际对应表

| 运动段 | 缩放值来源 | TCP 限速来源 | 当前值 |
|---|---|---|---|
| 当前位 → SCAN | YAML `moveit` | 无单独 TCP 限速 | 0.05 / 0.05 |
| SCAN → PREGRASP | YAML `moveit` | 无单独 TCP 限速 | 0.05 / 0.05 |
| PREGRASP → VERIFY | Python 固定 | YAML `cartesian` | 0.05 / 0.05，10 mm/s |
| VERIFY → GRASP | Python 固定 | YAML `grasp_cartesian` | 0.03 / 0.03，6 mm/s |
| GRASP → LIFT | Python 固定 | YAML `lift_cartesian` | 0.03 / 0.03，10 mm/s |
| LIFT → RELEASE | Python 固定 | YAML `lift_cartesian` | 0.03 / 0.03，10 mm/s |
| RELEASE → PREGRASP | Python 固定 | YAML `lift_cartesian` | 0.03 / 0.03，10 mm/s |
| PREGRASP → SCAN | YAML `moveit` | 无单独 TCP 限速 | 0.05 / 0.05 |

如果以后希望所有速度都只改 YAML，需要把 Python 中的 `0.05/0.03`
提取为配置字段。当前成功代码先保持不动。

## 3. 抓取高度和行程在哪里改

配置位置：

```yaml
targets:
  pregrasp_above_apple_m: 0.10
  verify_above_apple_m: 0.03
  grasp_above_apple_m: 0.015
  lift_m: 0.20
```

说明：

| 参数 | 当前值 | 含义 |
|---|---:|---|
| `pregrasp_above_apple_m` | 0.10 m | 苹果上方 100 mm 的预抓取点 |
| `verify_above_apple_m` | 0.03 m | 苹果上方 30 mm 的检查点 |
| `grasp_above_apple_m` | 0.015 m | TCP 目标在视觉苹果中心上方 15 mm |
| `lift_m` | 0.20 m | 闭爪后上抬 200 mm |

常见调整：

- 夹爪仍碰桌面：先把 `grasp_above_apple_m` 从 0.015 增至 0.018 或 0.020；
- 夹取位置太高：每次只降低 0.002～0.003 m，并先用人工确认模式测试；
- 预抓取想更高：增加 `pregrasp_above_apple_m`；
- 上抬距离太大或工作区边缘 LIFT 不可达：适当减小 `lift_m`。

`grasp_above_apple_m` 是高风险参数。数值减小代表 TCP 更向下，可能碰桌面；不要一次修改 10 mm 以上。

## 4. 夹爪开合参数在哪里改

配置位置：

```yaml
modbus_gripper:
  open_mm: 80.0
  close_mm: 20.0
  close_settle_s: 1.0
```

说明：

- `open_mm`：开始识别、移动和释放后的夹爪开度；
- `close_mm`：抓苹果时发送的位置目标，不是力；
- `close_settle_s`：闭合后等待多久再上抬。

当前成功值：

```text
打开 80 mm
闭合目标 20 mm
等待 1 s
```

苹果容易滑落时，可以把 `close_mm` 从 20 改为 18 或 15 mm，但必须观察是否过度挤压。数值越小，夹爪闭得越紧。

以下通信参数正常时不要修改：

```yaml
port: 1
baudrate: 9600
tool_voltage: 3
device_address: 1
position_register: 43
steps_per_mm: 2240
```

不要在自动抓取流程中增加 `initialize()` 或机械回零。

## 5. 苹果视觉采样门禁在哪里改

抓取程序的二次检查位于：

```yaml
vision:
  sample_count: 10
  timeout_s: 50.0
  max_axis_span_m: 0.010
  min_confidence: 0.15
  min_radius_m: 0.020
  max_radius_m: 0.080
```

说明：

| 参数 | 当前值 | 作用 |
|---|---:|---|
| `sample_count` | 10 | 抓取前需要的连续有效样本数 |
| `timeout_s` | 50 s | 等待样本的最长时间 |
| `max_axis_span_m` | 0.010 m | 任一 XYZ 轴最大峰峰波动 |
| `min_confidence` | 0.15 | 抓取程序接受的最低置信度 |
| `min_radius_m` | 0.020 m | 苹果半径下限 |
| `max_radius_m` | 0.080 m | 苹果半径上限 |

调整建议：

- 偶尔只能收到 6～8 个样本：优先增加 `timeout_s`，不要先降低样本数；
- 识别稳定但等待太久：可把 `sample_count` 改为 8；
- 坐标跳动仍被接受：把 `max_axis_span_m` 降到 0.006～0.008；
- 不要为了一次低置信度识别把 `min_confidence` 降得很低。

苹果定位节点本身还有第一道检测阈值，位于：

```text
$APPLE_CATCH_ROOT/apple_pick_v2/apple_center_localizer_v2.py
```

对应常量：

```python
MIN_CONFIDENCE = 0.15
MAX_SYNC_ERROR_NS = 100_000_000
```

定位频率默认：

```python
--inference-hz 2.0
```

当前一键 launch 没有向定位节点额外传递 `--inference-hz`，因此使用默认
2 Hz。修改这些 Python 参数后需要重启苹果定位节点或完整 launch。

注意：YAML 的 `vision.min_confidence` 是抓取前二次门禁；Python 的
`MIN_CONFIDENCE` 是 YOLO 是否发布苹果的第一道门禁。两者都要通过。

## 6. 抓取姿态候选在哪里改

配置位置：

```yaml
candidate_search:
  yaw_offsets_deg: [0, 90, 180, 270]
  pitch_stages_deg:
    - [0]
    - [10, -10]
    - [20, -20]
  max_abs_pitch_deg: 20
  ik_total_solver_budget_s: 0.080
  full_planning_time_s: 5.0
  full_planning_attempts: 3
```

含义：

- 先尝试完全垂直的 pitch 0°；
- 垂直候选全部失败才尝试 ±10°；
- 再失败才尝试 ±20°；
- yaw 只改变两指在水平面内的方向；
- 每个路点的多种子快速 IK 总预算为 80 ms；
- 最佳候选的完整规划最多 5 s、3 次尝试。

当前候选已经在真机验证过，包括自动选择 pitch +20° 的成功抓取。通常不要为了“看起来更快”删除候选。若规划经常超时，可先把
`full_planning_time_s` 从 5 增至 8，而不是放宽碰撞或关节限制。

## 7. SCAN 鸟瞰位在哪里改

配置位置：

```yaml
scan:
  joints:
    joint1:  2.510152891
    joint2:  0.354521179
    joint3:  0.647129746
    joint4:  0.061472860
    joint5:  2.045541343
    joint6: -0.071433319
  tolerance_rad: 0.015
```

这不是普通点位。当前八点 XY 视觉模型是在这个 SCAN 下采集的。只要修改了
SCAN 关节角、相机安装位置、手眼外参或 TCP，就必须重新测量视觉偏差并重新拟合模型。

`tolerance_rad` 只决定“多接近 SCAN 才算到位”，不是运动速度。不要用增大容差来掩盖机械臂没有准确回位。

## 8. 视觉 XY 校正模型在哪里

配置位置：

```yaml
visual_xy_correction:
  enabled: true
  scale: 0.9249983311376341
  rotation_deg: 2.2829447233570446
  translation_xy_m: [0.01199984868, -0.00628986080]
  valid_visual_x_m: [0.22, 0.50]
  valid_visual_y_m: [-0.33, 0.00]
  max_correction_m: 0.050
```

这些是 8 组真实测量拟合出的模型参数，已经通过真机抓取验证。不要凭目测修改
`scale`、`rotation_deg` 或 `translation_xy_m`。

需要临时关闭模型进行对比时，不必改文件，启动时增加：

```text
--disable-visual-xy-correction
```

有效范围是保护门禁。苹果超出范围时程序失败即停，不应简单扩大范围后继续真机抓取；应先重新采集该区域的数据。

## 9. 桌面和碰撞模型在哪里改

配置位置：

```yaml
scene:
  support_guard_footprint_diameters: 5.0
  table_safety_inflation_m: 0.002
  table_size_xyz_m: [0.75, 1.20, 0.10]
  table_center_xy_m: [0.425, -0.10]
  camera_box_xyz_m: [0.11, 0.05, 0.05]
```

说明：

- 支撑面 Z 高度暂时由苹果中心和苹果半径推算；
- `support_guard_footprint_diameters` 设置局部正方形保护范围的边长，
  当前为苹果直径的 5 倍，中心跟随苹果 X/Y；
- `table_safety_inflation_m` 再向上增加安全层；
- `table_size_xyz_m` 的第三项继续提供碰撞体厚度；前两项以及
  `table_center_xy_m` 只在局部倍数被删除或设为 0 时作为旧模式回退；
- `camera_box_xyz_m` 是 RealSense 的保守碰撞包络。

例如半径为 29.5 mm 的苹果，直径约为 59 mm，5 倍局部保护范围约为
`0.295 × 0.295 m`。该临时模式避免把高平台扩展到整个工作区，但平台范围外的障碍物不会被建模；最终仍应改为过滤点云 OctoMap。

当前 2 mm 支撑面安全膨胀已经在真实桌面抓取中验证。减小它可能让规划更容易，但会降低保护；增大它可能导致实际可抓、MoveIt 却报碰撞。不要用修改碰撞体来解决视觉偏差。

以下相机外参不要作为普通参数修改：

```yaml
camera_translation_link6_m: [...]
camera_quaternion_link6_xyzw: [...]
```

它们来自手眼标定。

## 10. 安全门禁在哪里改

配置位置：

```yaml
safety:
  service_timeout_s: 10.0
  motion_timeout_s: 180.0
  max_joint_delta_rad: 5.00
  max_tcp_final_error_m: 0.005
  tcp_stable_time_s: 1.0
```

说明：

- `service_timeout_s`：等待 MoveIt 服务；
- `motion_timeout_s`：等待规划或真实执行结束；
- `max_joint_delta_rad`：轨迹相对当前关节位置允许的最大变化，不是速度；
- `max_tcp_final_error_m`：TCP 到位误差上限，当前 5 mm；
- `tcp_stable_time_s`：到位后需要稳定的时间。

不要通过增大 `max_joint_delta_rad`、`max_tcp_final_error_m` 来强行通过失败门禁。机械臂不可达、碰撞、坐标错误和速度慢是不同问题。

## 11. 不建议人工修改的参数

除非重新标定或明确知道机械模型变化，否则不要改：

- `frames.base`、`frames.tcp`；
- `targets.vertical_yaw_rad`；
- `candidate_search.joint_lower_limits_rad`；
- `candidate_search.joint_upper_limits_rad`；
- `candidate_search.ik_seed_offsets_rad`；
- `visual_xy_correction` 的拟合参数；
- 相机相对 Link6 的平移和四元数；
- RS485 寄存器、设备地址和 `steps_per_mm`；
- `cartesian.jump_threshold` 和关节跳变门禁；
- `Link6 → tcp_link = 0.138 m`。

## 12. 修改后的安全验证顺序

只改速度时：

1. 保存 YAML；
2. 停止上一轮抓取程序；
3. 先用 `--preflight-only` 检查当前苹果的完整路径；
4. 再用带人工确认的模式执行一轮；
5. 观察轨迹、振动、夹爪晃动和到位误差；
6. 确认正常后再使用 `--fully-autonomous`。

预检命令：

```bash
$APPLE_YOLO_PYTHON \
  $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp.py \
  --config $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp_manual.yaml \
  --preflight-only --operator-confirmed --return-after-lift
```

人工确认模式：

```bash
$APPLE_YOLO_PYTHON \
  $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp.py \
  --config $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp_manual.yaml \
  --execute --operator-confirmed --return-after-lift
```

全自动单轮：

```bash
$APPLE_YOLO_PYTHON \
  $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp.py \
  --config $APPLE_CATCH_ROOT/apple_pick_v2/single_apple_full_grasp_manual.yaml \
  --execute --operator-confirmed --fully-autonomous
```

## 13. 最常改的参数速查

| 想改变什么 | 修改位置 | 参数 |
|---|---|---|
| 去 SCAN、去 PREGRASP 更快 | YAML `moveit` | `velocity_scaling`、`acceleration_scaling` |
| 接近 VERIFY 更快 | YAML `cartesian` | `max_tcp_speed_m_s` |
| 最后下降更快/更慢 | YAML `grasp_cartesian` | `max_tcp_speed_m_s` |
| 上抬和放回更快/更慢 | YAML `lift_cartesian` | `max_tcp_speed_m_s` |
| 抓得更紧 | YAML `modbus_gripper` | 减小 `close_mm` |
| 夹爪打开更宽 | YAML `modbus_gripper` | 增大 `open_mm` |
| 抓取点更高、避免碰桌 | YAML `targets` | 增大 `grasp_above_apple_m` |
| 抓取点更低 | YAML `targets` | 小幅减小 `grasp_above_apple_m` |
| 上抬距离 | YAML `targets` | `lift_m` |
| 等苹果样本更久 | YAML `vision` | 增大 `timeout_s` |
| 减少采样帧数 | YAML `vision` | `sample_count` |
| 调 YOLO 第一层阈值 | `apple_center_localizer_v2.py` | `MIN_CONFIDENCE` |
| 调识别频率 | `apple_center_localizer_v2.py` | `--inference-hz` 默认值 |
| 扩大抓取倾角 | YAML `candidate_search` | `pitch_stages_deg`、`max_abs_pitch_deg` |

## 14. 当前成功速度基线

```yaml
moveit:
  velocity_scaling: 0.05
  acceleration_scaling: 0.05

cartesian:
  max_tcp_speed_m_s: 0.010

grasp_cartesian:
  velocity_scaling: 0.03
  acceleration_scaling: 0.03
  max_tcp_speed_m_s: 0.006

lift_cartesian:
  velocity_scaling: 0.03
  acceleration_scaling: 0.03
  max_tcp_speed_m_s: 0.010
```

如果不确定改动是否安全，恢复以上数值就是 2026-08-10 已真机成功的低速基线。
