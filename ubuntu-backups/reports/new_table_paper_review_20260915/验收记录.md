# 铺纸后只定位验收（2026-09-15）

用户限定只定位、不抓。A完成50秒只读采集与离线识别，根独立审查原始图、RGBD时间夹逼、坐标转换及定位实现。没有执行运动/夹爪动作，也没有发布可执行目标或修改生产场景。

25组同步样本，首末照片场景未见明显变化；按真实关节FK计算相机原点每轴变化不足0.031mm。纸面仍有时变读数：像素(170,170)周围7×7区域逐帧中位深度547–588mm并缺测，(390,330)528–543mm，(355,250)537–566mm。根独立纸面ROI拟合的同点高度变化约21mm，不能验收为准确稳定的新桌面。不能由此唯一确定是材质、曝光、USB传输还是其他深度问题。

旧YOLO首帧检测6个橘子实例：O0底部截断、O2盆内左侧截断，O1/O3/O4/O5为纸上果簇局部可见果实；置信度约0.22–0.33，肉眼可见部分果实未被检测。首帧分割mask在同一静止场景25帧使用，不代表跨运动追踪能力。通过项仅为二维检测和标注输出。

三维诊断复用旧estimate_points，记录sphere-fit/fallback、表面点与估算球心，历史XY补偿未应用；所有usable_3d=false。旧RANSAC种子逐帧变化，原中心跨度不能全部归因于传感器；根要求A补同帧多种子、跨帧固定种子的对照。三维结果保持诊断用途，不作为可执行定位验收。
