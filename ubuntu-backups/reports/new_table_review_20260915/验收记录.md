# 新桌面模型验收：暂不通过（2026-09-15）

A已完成不移动机械臂的50秒采集；根独立读取原始数据、复算平面和时间/变换一致性。尚未完成可启用的新桌面碰撞模型，不执行旧抓取轨迹。

## 通过的部分

- 25组RGB-D时间戳均位于真实关节状态读数夹逼范围内，最大夹逼约0.155秒；RGBD同步误差为0。
- 实际安装URDF与源码哈希一致，FK主链使用真实关节、旧手眼变换、相机内部静态TF；控制器pose仅归档，不冒充法兰坐标。
- 对齐深度与彩色处于同一光学坐标系，记录的畸变系数全0。
- 记录期间相机原点（按真实关节FK计算）每轴变化不足0.03mm，关节变化不足0.006度；不能解释明显深度漂移。

## 不通过的原因

- 固定桌面像素(90,400)周围9×9区域的逐帧中位深度约469–549mm，并有缺测；另一片(400,400)约518–535mm。
- 根独立选3个ROI重新拟合，跨帧同一XY预测高度变化约7.7mm。A筛选稳定像素后的探索性拟合仍有约6.6mm同点高度变化。局部低残差不能证明平面绝对准确或稳定。
- 当前光学投射器参数为启用、功率150，自动曝光开启；未确定绿色桌面材质、弱纹理或传输异常各自影响。驱动此前有残帧警告，不能仅以“有深度话题”判定通过。
- 相机仅看到桌面的部分区域，未测完整桌边和盆的基座坐标；旧手眼绝对精度及真实指尖外形未在新桌面验收。
