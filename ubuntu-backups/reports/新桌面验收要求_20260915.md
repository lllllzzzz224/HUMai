# 新桌面模型验收要求

根验收，A实施；仅非运动采集、离线拟合和模型候选。生产抓取未授权在此阶段重启。

1. 使用本次新桌面原始RGBD，保留时间戳、实际对齐深度内参、相机内部TF、真实关节读数、原始状态包及单位换算。同步不成立的样本拒绝。
2. 基座系变换优先真实关节与运行URDF的FK；控制器姿态需确认活动工具/工作系后交叉校验。不能把控制器TCP姿态直接当法兰。
3. 当前绿色桌面与右侧地面、盆、果实、拼缝分别辨认。ROI跨可见工作区，保留标注图；报告局部覆盖、残差分布、帧间稳定性及有效点率。拟合残差不是手眼绝对精度。
4. 未观察桌边不猜完整尺寸；可交付可见区域内模型及范围约束，未覆盖区域列待测。测得平面与保守碰撞保护面分别记录。
5. 原程序每轮apply_scene按果球重建apple_test_table_guard，清理时remove_support_guard会删除它。新测量模型必须有明确的防覆盖与生命周期策略，不能发布一次就宣称抓取会使用。
6. 源码与install rm_65.urdf哈希已确认一致。TCP相对Link6为138mm；夹爪80×80×170mm盒体不是实测夹指外形，保留此限制。
7. 验收需独立复算原始数据并检查实现/配置差异。测量可用、模型可用与可抓取分别表述；未测盆位置、深度残帧、未核验手眼、未确认实际指尖净空均不得隐瞒。
