## 2. 核心问题排查与技术突破

### 问题一：夹爪物理起吊滑脱与假树枝干涉
- **现象**：机械臂下探至抓取位并闭爪，但在垂直起吊瞬间，果实从指缝滑落或被假树枝挤开。
- **根因分析**：
  1. **夹持时序不足（`close_settle_s`）**：Modbus RTU 夹爪从 80mm 全开位置闭合到果径（约 60mm）需要约 1.8 秒机械行程时间。原配置中 `close_settle_s` 仅为 1.0 秒，导致夹爪指尖尚未完全压紧果面建立静摩擦力，手臂就已触发笛卡尔向上抬升，造成物理打滑。
  2. **物理避障与虚拟场景差异**：MoveIt 碰撞场景仅建有平整虚拟桌面（碰撞体），环境中用于悬挂果实的塑料假藤蔓在规划器中不可见。若带有俯仰角（Pitch 20°）进刀，夹爪侧翼会推挤假树枝，导致树枝反弹拨开果实。
- **解决方案**：
  1. 将 `close_settle_s` 由 1.0 秒提升至 **2.5 秒**，确保夹爪电机走到堵转/目标位置并维持稳压后才起吊；
  2. 人工理顺假树枝，采摘策略优先收敛至 Stage 0（**`Pitch 0°` 纯垂直顶入**），实现最小水平截面进刀。

### 问题二：红苹果轻量级 YOLO 检测漏检（置信度 0.04）
- **现象**：当红苹果移至开阔白纸上后，使用全图及大尺寸条带切片（$480\times 480$）推理时，YOLO11n-seg 检出置信度暴跌至 0.04（低于 0.25 阈值），甚至将旁边的游标卡尺误识别为刀具并干扰上下文。
- **根因消融**：在固定鸟瞰扫描高度下，小果实（像素直径 $<80\text{px}$）在 $480\times 480$ 感受野中特征占比过低；但在 $240\times 240$ 局部切片中，果实特征凸显，置信度可高达 0.78~0.83。
- **解决方案（多尺度 SAHI 网格切片架构）**：
  - 在 `apple_center_localizer_v2.py` 中重构切片生成逻辑：生成 15 个 $240\times 240$ 密集滑动切片（步长 120px）以及 $480\times 480$ 全景切片；
  - RTX 4060 Ti GPU 支持 15 组切片并发 Batch 推理，耗时仅约 **$35\text{ms}$**，红苹果置信度提升至 **0.78**，橘子稳定在 **0.83**。

### 2. `apple_center_localizer_v2.py`（视觉定位与切片检测节点）
- **修改说明**：
  1. 重写 `inference_rois()` 方法，构建 $240\times 240$ 细粒度网格切片与 $480\times 480$ 粗粒度切片的多尺度组合；
  2. 增加 `--target` 命令行选项（`apple` / `orange` / `all`），根据用户指令动态切换 COCO 类别过滤；
  3. 增加目标空间锁定跟踪机制（`locked_uv`），避免在存在多个果实时画面跳变；
  4. 新增 `ransac_sphere_fit()` 3D 点云球面 RANSAC 拟合算法，提升深层点云抗噪能力。

```python
# 核心改变片段 1：多尺度切片生成 (Multi-scale SAHI Tiling)
@staticmethod
def inference_rois(width: int, height: int) -> list[tuple[int, int, int, int]]:
    rois = []
    # Multi-scale 1: 240x240 fine grid (stride 120px)
    tile_size = 240
    stride = 120
    for y0 in range(0, height - tile_size + 1, stride):
        for x0 in range(0, width - tile_size + 1, stride):
            rois.append((x0, y0, x0 + tile_size, y0 + tile_size))
    for y0 in range(0, height - tile_size + 1, stride):
        rois.append((width - tile_size, y0, width, y0 + tile_size))
    for x0 in range(0, width - tile_size + 1, stride):
        rois.append((x0, height - tile_size, x0 + tile_size, height))
    rois.append((width - tile_size, height - tile_size, width, height))

    # Multi-scale 2: 480x480 full-height coarse tiles
    tile_w = min(INFERENCE_TILE_WIDTH_PX, width)
    last_start = width - tile_w
    starts = list(range(0, last_start + 1, INFERENCE_TILE_STRIDE_PX))
    if not starts or starts[-1] != last_start:
        starts.append(last_start)
    for x0 in starts:
        rois.append((x0, 0, x0 + tile_w, height))

    # 去重
    seen = set()
    unique_rois = []
    for r in rois:
        if r not in seen:
            seen.add(r)
            unique_rois.append(r)
    return unique_rois

# 核心改变片段 2：多类别过滤与目标跟踪
```

## 4. 实验测试与执行结果

### 阶段一：红苹果自主采摘闭环
- **目标物**：真实红苹果（COCO class 47）
- **空间解算**：球心 `[0.4026, -0.1069, -0.0553] m`，估算物理半径 $R=31.8\text{mm}$，置信度 0.67；
- **姿态与预检**：自动命中最优 Stage 0（`Yaw 0°, Pitch 0°` 纯垂直顶入）；
- **执行闭环**：
  1. 空中 SCAN $\to$ 预抓取位 PREGRASP $\to$ 悬停核验 VERIFY（到位误差 $0.66\text{mm}$）；
  2. 笛卡尔直线探入 GRASP 位 $\to$ 闭爪夹取并**原位稳压 2.5 秒**；
  3. 笛卡尔直线竖直起吊 $7\text{cm}$（到位误差 $0.63\text{mm}$），物理稳固夹起悬空；
  4. 原路径下放回桌面放稳 $\to$ 夹爪开至 80mm $\to$ 机械臂平滑复位 SCAN；
- **执行结论**：`PASS_PICK_RETURN_COMPLETE`（100% 成功）。
