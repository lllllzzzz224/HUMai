# 新环境下真机橘子抓取入盆验证

## 目标

1. 验证更换实验环境（不同桌面、不同光照）后，RM65 机械臂与 RealSense D435 视觉抓取系统的环境自适应能力。
2. 验证无需手动测量桌面距离与无需重新建模目标水果的情况下，系统能否完成端到端视觉定位、自适应支撑面推导与单轮真机采摘入盆全闭环。
3. 排查并消除橘子定位中的系统性微小几何偏差，验证算法改进后的真机抓取效果。

## 已确定内容

- **通信与节点环境**：
  - Ubuntu 主机（`10.77.0.2`）与机械臂底座（`192.168.1.18`）网络通信正常。
  - 抓取全栈服务统一部署在 Ubuntu 后台 tmux 会话 `rm_stack`（`ROS_DOMAIN_ID=42`）。
- **空间几何与自适应机制**：
  - 桌面支撑面高度采用动态视觉推导：$Z_{\text{table}} = Z_{\text{fruit}} - R_{\text{fruit}} + \Delta_{\text{inflation}}$，动态生成局部碰撞保护面（`support_guard`，顶面 $Z = -0.101\text{ m}$）。
  - 水果采用 YOLOv11 实例分割 + 点云 3D RANSAC 球拟合动态解算，无需静态 3D 模型。
  - 盆子落料点位姿维持既有标定参数：`basin_place = [0.464, 0.006, -0.020] m`。

## 实验过程与现象

### 第一轮：首轮闭环抓取与定位偏差发现（21:16）

1. **环境准备与状态重置**：
   - 终止旧的孤立诊断测试进程，通过 `./arm_ctl start --target orange` 一键启动驱动、控制器、MoveIt 2 与视觉定位节点。
   - 针对机械臂启动时的微小关节角偏差（Joint 5 偏差约 7.6°），调用平缓回位脚本回到标准固定鸟瞰位（SCAN），最大关节误差控制在 $0.013\text{ rad}$，校验通过。
2. **目标识别与多段轨迹预检**：
   - 视觉节点稳定捕获工作区内橘子：
     - 原始三维中心：$[0.4130, -0.1790, -0.0639]\text{ m}$
     - 拟合半径：$39.3\text{ mm}$
   - MoveIt 完成链式规划预检，全部路径求解成功，求解率均为 100%（`fraction=1.0000`）。
3. **真机执行与现象**：
   - 夹爪完成单轮全自动抓取并入盆（状态 `PASS_PICK_PLACE_BASIN_COMPLETE`，总耗时 44s）。
   - **现场微小偏差现象**：夹爪下潜闭合时，物理两指没有完全居中正对橘子中心，存在轻微前偏（$+X$）且下潜深度略偏深。

### 根因分析与算法几何优化（21:24）

通过深入比对相机外参、三维点云与机械臂末端下潜路径，确认了根本诱因：
1. **倾斜光轴投影伪影（导致 XY 水平偏差 $+8.96\text{ mm}$）**：
   - SCAN 姿态下，相机光学原点位于 $[0.300, -0.171, 0.452]\text{ m}$，以约 $13.4^\circ$ 的前倾斜角俯视果实（果实位于 $X \approx 0.404\text{ m}$）。
   - 传统算法在相机坐标系内沿视线方向将球心向后推移一个半径 $R$。转换到基座标系后，该投影向量产生了分量 $\Delta X = R \cdot \sin(13.4^\circ) \approx +8.96\text{ mm}$。
   - 而物理放置于水平桌面上的静止果实，其重力对称轴正对表面顶点。机械臂垂直下潜抓取时，水平目标必须正对顶点 $(X_{\text{surface}}, Y_{\text{surface}})$，否则夹爪会向前虚偏约 $9\text{ mm}$。
2. **扁椭球体几何退化（导致 Z 轴深度偏深约 $10\text{ mm}$）**：
   - 橘子属于扁椭球体（垂直高度显著小于水平赤道直径，纵横比约 $0.72$）。正球体拟合推导的球心比实际物理几何中心低约 $10\text{ mm}$，导致抓取点深度过深、过度逼近桌面。
3. **算法工程改进**（已在 `apple_center_localizer_v2.py` 实装生效）：
   - **水平锚定**：将基座标系下的水平目标点严格锚定为表面点云顶点 $(X_{\text{surface}}, Y_{\text{surface}})$，消除倾斜光轴引起的水平投影漂移。
   - **纵横比约束**：针对橘子（类别 49）引入垂直有效半径比率 $Z_{\text{aspect}} = 0.72$，修正物理中心深度与抓取下潜基准。

### 第二轮：算法修正后真机抓取复验（21:26）

1. **服务热重载与目标更新**：
   - 重新加载服务栈生效新算法，视觉节点重新锁定橘子：
     - 表面顶点：$[0.3578, -0.2753, -0.0264]\text{ m}$
     - 修正后球心：$[0.3573, -0.2745, -0.0552]\text{ m}$
     - 水平偏差：$\Delta X = -0.54\text{ mm}, \Delta Y = +0.82\text{ mm}$（从首轮的 $8.96\text{ mm}$ 降至亚毫米级）
     - 下潜抓取点：$Z = -0.0402\text{ m}$（位于果顶下方 $13.8\text{ mm}$，精准处于橘子赤道上边缘）。
2. **真机全流程执行**：
   - `21:26:45` 启动真机抓取；
   - `21:27:04` 到位 `GRASP`，到位误差 $0.68\text{ mm}$，夹爪垂直下潜精准居中包络果实两端，原位平稳闭合，毫无侧向推挤；
   - `21:27:10` 垂直起吊 $70\text{ mm}$，果实牢固被夹持悬空脱离桌面；
   - `21:27:21` 平稳横移至盆口上方并下探入盆，释放橘子滑入盆底；
   - `21:27:31` 垂直回抽并返回空中 SCAN，总耗时 46 秒，圆满成功。
