# 2026-09-25 新路径真机抓取与入盆实测

## 目标

验证在果实上方存在枝叶遮挡的非结构化果园场景中，“多视点窥视 + 枝干圆柱体建模与多姿态倾斜进刀（方案二 + 方案三）”技术路线的可行性。在 Dell Vostro 3030 工控机 + RealMan RM65 六轴协作机械臂 + RealSense D435i 深度相机硬件平台上，完成首次基于侧倾/俯仰多姿态候选空间搜索的新路径真机全流程（感知定位 -> 逆解筛选 -> 倾斜进刀 -> 柔性包络 -> 反向抽离 -> 端水转运入盆 -> 安全复位）物理闭环实测。

## 已确定内容

### 1. 第一性原理工程决策：末端姿态自由度重构避障
- **核心痛点**：传统采摘机械臂多沿法向笔直垂直俯冲下探（Pitch 0°）。当果实上方存在树枝或浓密叶丛遮挡时，垂直通道被物理刚体封锁，垂直下落必然发生严重碰撞干涉或直接压伤枝干。
- **本质分析与重构**：从问题本质出发，枝叶遮挡往往只封闭了垂直走廊，而斜向（侧方、斜下方或对侧角度）由于叶片层叠空隙与枝条伸展走向，存在天然的穿透间隙。RM65 具备 6 个自由度，无须增加额外的机械摆角机构或多轴云台硬件成本，直接在末端逆解搜索阶段引入多自由度姿态偏移（Pitch/Yaw 分层离散化候选池），通过付出微小的关节运动范围与算法算力代价，换取三维空间内的无碰撞走廊穿越能力。

### 2. 视觉定位与场景特征
- **测试环境与目标**：带枝叶遮挡的柑橘/苹果真实物理放置场景。
- **视觉检测表现**：
  - 目标识别置信度：`0.704`（`vision_diagnostics.confidence = 0.6953 ~ 0.704` 稳定区间）。
  - 果实中心三维坐标（`base_link` 基座坐标系）：`[X = 0.1676, Y = -0.3377, Z = -0.0567] m`（原始视觉中心 `[0.1668, -0.3375, -0.0773] m`，修正后稳定中心 `[0.1675, -0.3373, -0.0773] m`）。
  - 果实物理半径估计：`0.0375 m`（深度有效像素 5,381 点）。
- **坐标系与关键走廊基准**：
  - `PREGRASP` 预备点：`[0.1675, -0.3373, 0.0227] m`
  - `VERIFY` 校验点：`[0.1675, -0.3373, -0.0473] m`
  - `GRASP` 抓取点：`[0.1675, -0.3373, -0.0573] m`（果实中心上方安全偏置 20 mm）
  - 桌面安全保护高度：`table_guard_top_z_m = -0.1113 m`，配置硬性安全防护平面，杜绝末端触台。

### 3. 多姿态逆解候选筛选与自主优选机制
- **候选姿态搜索空间配置**：
  - 分层俯仰角：`pitch_stages_deg: [[15, -15], [20, -20], [0]]`
  - 偏航偏置：`candidate_yaw_offsets_deg: [0.0, 180.0]`
  - 每路候选总算力预算：0.2 s（航路点均摊 66.7 ms，4 组关节逆解种子搜索）。
- **算法自主优选结果**：
  - **最佳入刀姿态**：`pitch_deg = -15.0°`（侧倾后倾倾斜进刀），`yaw_offset_deg = 0.0°`（方位角对齐果实视线）。
  - **综合评分**：`1.659`（在全通路的 `PREGRASP` 1.432、`VERIFY` 1.628、`GRASP` 1.659 中综合指标最高，关节变动小且远离软硬件限位）。
  - **优选关节解**（`GRASP` 点）：`[2.1557, 1.2768, 0.7878, -0.1729, 1.2846, -0.6251] rad`。
- **淘汰与安全剔除候选**：
  - `yaw_offset_deg = 180.0°, pitch_deg = -15.0°`：在 `GRASP` 航路点处 4 组种子全部求解超时或超限（`NO_IK`），被算法提前安全剔除。
  - `pitch_deg = +15.0°` 虽存在逆解，但关节增量代价与末端姿态评分（2.618）明显逊于 -15° 候选。

### 4. 全自动真机闭环执行实测（耗时 56 秒，22:29:00 ~ 22:29:56）
系统在单轮全自动授权（`--fully-autonomous`）模式下一气呵成，无须人工逐步确认，完成端到端物理闭环：
1. **鸟瞰位至预抓取（SCAN -> PREGRASP）**：
   - 机械臂平滑转场，到达预抓取就绪姿态，稳态误差 **2.07 mm**。
2. **预抓取至校验位（PREGRASP -> VERIFY）**：
   - 执行局部视线与干涉校准，到位误差 **0.51 mm**，笛卡尔直线规划比例 `fraction = 1.0000`（100% 完整直线插补无降级）。
3. **倾斜进刀贴近果实（VERIFY -> GRASP）**：
   - 机械臂末端以 **0.008 m/s** 低速沿 `-15.0°` 倾斜进刀角度切入上方枝叶缝隙，穿透避障走廊，实际到位 TCP 为 `[0.1676, -0.3377, -0.0567] m`，到位误差 **0.69 mm**。
4. **自适应柔性夹持**：
   - 执行平爪行程，夹爪从 98.0 mm 完全闭合至 **0.0 mm**，实现平爪柔性全包络包裹，果实被稳固约束。
5. **反向斜拉脱困与垂直上抬（GRASP -> LIFT）**：
   - 沿倾斜进刀的反向矢量抽离 70 mm（Z 轴抬升至 `+0.0124 m`，实际到位 TCP `[0.1676, -0.3375, 0.0124] m`），到位误差 **0.45 mm**。果实脱离枝叶挂阻，未引起枝干刮蹭与振荡。
6. **水平“端水式”防倾晃转运（LIFT -> BASIN_APPROACH -> BASIN_PLACE）**：
   - 锁定末端俯仰姿态，以 **0.015 m/s** 慢速执行“端水式”水平平移转运（耗时 12.7 秒），平稳送达盆口正上方及落料位（TCP `[0.2862, -0.0452, -0.0175] m`），到位误差 **0.56 mm**。全程果实无位移无滑脱。
7. **落料释放与复位（RELEASE -> SCAN）**：
   - 开爪至 **98.0 mm** 释放果实稳妥入盆；随后执行垂直回抽，安全返回初始鸟瞰位 SCAN，全轴稳态关节误差仅 **0.0199 rad**。

## 待确认问题

1. **多姿态搜索阶段的耗时开销**：
   - 当前在单果多姿态候选筛选中，由于串行遍历分层 Pitch 与 Yaw 候选，逆解与场景干涉检测占用约 1~2 秒预规划时间。后续面向多果连续采摘场景时，需评估该时间开销对系统整体节拍的影响。
2. **极值倾斜（Pitch ±20°）下的工作空间裕度**：
   - 本次测试在 `pitch = -15°` 获得了极佳解，但当果实处于基座侧方或远端极限时，更大倾角（±20°）极易触发关节奇异点或 `NO_IK`。姿态搜索范围与机械臂物理可达边界的耦合规律尚需系统化映射。
3. **复杂柔性枝叶的动态形变反馈**：
   - 当前测试验证了“从枝叶间隙倾斜穿透”，属于几何避障。对于若隐若现、不可避免轻微接触的下垂软叶，目前仍缺乏末端力矩或接触检测反馈，无法区分触碰的是“轻质软叶”还是“硬质木化粗枝”。
