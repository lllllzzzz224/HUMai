# 新主机（Dell Vostro 3030）Ubuntu 机械臂运行栈部署记录

- 记录日期：2026-09-21
- 当前阶段：新工控计算平台环境迁移与全自动部署落地
- 涉及主机：Mac 本地终端、新主机 Dell Vostro 3030 (`humai@10.77.0.2`)、RealMan RM65-B 机械臂 (`192.168.1.18`)

## 目标

在新购置的 Dell Vostro 3030 商用台式主机上，将其从原生 Windows 11 迁移安装为 Ubuntu 24.04.5 LTS，并全自动完成 RM65 机械臂控制栈、ROS 2 Jazzy、MoveIt 2、RealSense D435 相机驱动、以及 YOLOv11 实例分割视觉抓取环境的完整部署与 Mac 端控制台联动适配。

## 已确定内容

### 1. 硬件规格与系统拓扑

- **整机型号**：Dell Vostro 3030 台式主机
- **处理器 (CPU)**：12th Gen Intel Core i5-12400（6 性能大核 / 12 线程，最高睿频 4.40 GHz，L3 18MB）
- **内存 (RAM)**：16 GB（实际可用约 13 GB，Swap 4 GB）
- **硬盘 (SSD)**：1 TB NVMe SSD（WD Green SN350 1TB，Ubuntu 根目录分配 268 GB，可用 239 GB）
- **显卡 (GPU)**：Intel UHD Graphics 730（核显）
- **通信拓扑**：
  - 板载千兆网卡 `enp1s0`（固定 IP `10.77.0.2/24`）与 Mac (`en14`，`10.77.0.1/24`) 直连，物理往返延迟 ~0.55ms；
  - 自动保留校园 Wi-Fi (`HUBU-STUDENT`) 作为默认路由，支持外网更新与包下载；
  - Mac 端 SSH 免密密钥与 sudo 免密提权均已固化。

### 2. 软件运行栈部署明细

1. **路径无缝映射**：
   - 建立了系统软链接 `sudo ln -s /home/humai /home/li`；
   - 彻底解决了老工程中几百个脚本对 `/home/li/...` 的硬编码依赖，双向路径完全通用。
2. **ROS 2 与机器人包 (ROS 2 Jazzy)**：
   - 安装了官方源与中科大镜像 `ros-jazzy-desktop`、`ros-jazzy-moveit`、`ros-jazzy-ros2-control`、`ros-jazzy-realsense2-camera` 等；
   - 在 `/home/humai/ros2_ws` 下拉取了睿尔曼官方 `ros2_rm_robot`；
   - 修复了 MoveIt 2 在 ROS 2 Jazzy 下的 C++ 接口弃用改动（`Plan.trajectory_` -> `Plan.trajectory`）；
   - 成功编译全部 22 个 ROS 2 软件包（`rm_driver`, `rm_control`, `rm_description`, `rm_65_config`, `rm_moveit2`, `rm_rl_grasp` 等），构建耗时仅 9.47s。
3. **视觉与 YOLO 虚拟环境**：
   - 搭建了 `/home/humai/ros_yolo_env`（软链接至 `/home/humai/anaconda3/envs/yolo11`）；
   - 安装了针对 12 代 CPU 优化的 `PyTorch 2.14.0+cpu`、`ultralytics 8.4.x`、`Robotic_Arm 1.1.6`、`opencv-python`、`pyrealsense2`；
   - 实测 CPU AVX2 推理 YOLO11n-seg 单帧延迟稳定在 **36.3 ms（约 27.5 FPS）**，满足实时采摘引导需求。
4. **控制台与网络自愈工具链升级**：
   - Mac 端入口 `scripts/arm_ctl.py` 默认目标主机更新为 `humai@10.77.0.2`；
   - 在 Ubuntu NetworkManager 中配置了 `Robot-Arm` 自动匹配规则（匹配任意 `enx*`、`eth1-9`、`usb0` 网卡，自动绑定 `192.168.1.100/24` 且保留默认网关），实现机械臂网卡即插即用；
   - Ubuntu 端脚本 `scripts/remote_stack.sh`（`/home/humai/hand_eye_calibration/scripts/robot_stack_manager.sh`）增加网卡自动探测函数 `detect_robot_net_if()`，智能识别机械臂网卡。
5. **系统固化与离线仿真验证**：
   - 固化 `ssh.service` 开机自动拉起，屏蔽系统休眠挂起（`systemctl mask sleep.target suspend.target`），防止作为工控主机时后台意外断连；
   - 在 `~/.bashrc` 中写入 ROS 2 Jazzy 环境初始化、`ROS_DOMAIN_ID=42` 及 `arm_ctl`、`yolo_python` 终端快捷指令；
   - 运行工程全量单元测试（抓取状态机、路径解析、到达容差等）：**25 项测试全部通过（25 passed in 0.60s）**；
   - 离线拉起 MoveIt 2 规划器（`rm_group_controller` 与 `joint_state_broadcaster`），确认轨迹规划核心无报错上线。
