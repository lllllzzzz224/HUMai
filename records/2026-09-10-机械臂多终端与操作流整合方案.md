# 机械臂多终端与操作流整合方案

- 记录日期：2026-09-10
- 当前阶段：工程效率工具链重构与控制台落地
- 涉及主机：Mac 本地终端、Ubuntu 24.04 (`li@10.77.0.2`)、RealMan RM65-B 机械臂 (`192.168.1.18`)

## 目标

解决以往真机苹果/水果抓取实验中需要开启 4~5 个终端、手动多次 SSH、手动配置 ROS/Conda 环境变量、频繁残留孤儿进程等高重复劳动痛点，构建一套基于 Mac-Ubuntu 联动的单入口智能控制台 (`arm_ctl`)，并在兼顾极简体验的同时保留真机物理安全拦截。

## 已确定内容

### 1. 架构拓扑与分工

- **Mac 端入口 (`scripts/arm_ctl.py` / `./arm_ctl`)**：
  - 纯 Python 3 编写，零第三方库依赖；
  - 具备全链路自检 (`doctor`)、基础设施一键拉起 (`start`)、状态监控 (`status`)、安全抓取 (`grasp`)、进程清理 (`stop`)、实时日志 (`logs`)、快捷 SSH (`ssh`)；
  - 无参数运行提供交互式菜单（TUI），亦支持标准 CLI 命令调用；
  - 针对真机物理运动模式（`single` / `continuous` / `verify`），设立不可跳过的显式交互式安全确认窗口。
- **Ubuntu 端调度器 (`/home/li/hand_eye_calibration/scripts/robot_stack_manager.sh`)**：
  - 基于 `tmux` 会话 (`rm_stack`) 运行 `apple_hand_eye_all.launch.py`；
  - 固化启动时序（驱动 -> MoveIt -> 相机与 TF -> 视觉反投影）；
  - 具备话题心跳轮询能力（检测 `/joint_states`、`/camera/camera/color/image_raw`、`/apple_rviz/centre`）；
  - 提供退出信号级捕获与进程树全量清理（SIGINT -> SIGTERM/KILL），彻底杜绝 `static_transform_publisher` 与 RealSense 孤儿残留。

### 2. 诊断与实测验证记录

- **网络连通性**：
  - Mac 直连 Ubuntu (`10.77.0.2`)：RTT ~0.5ms。
  - Ubuntu 直连机械臂控制器 (`192.168.1.18`)：RTT ~0.47ms。
- **硬件外设**：
  - Intel RealSense D435 挂载在 USB 总线（Bus 002 Device 036）。
  - YOLO Python 环境可用：`/home/li/anaconda3/envs/yolo11/bin/python`。
- **清理与自检验证**：
  - 在首次诊断中成功识别出此前遗留的 6 个后台孤儿进程（含 2 个相互冲突的 `static_transform_publisher`）；
  - 执行 `arm_ctl stop` 后，所有孤儿进程及 ROS daemon 成功被安全重置；
  - 再次执行 `arm_ctl doctor`，全链路自检 4 项测试全部输出 `[PASS]`。
