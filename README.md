# HuMai - 协作机械臂复杂果簇自主采摘与入盆控制系统

本项目针对复杂果簇与枝叶遮挡环境下果实自主识别、精准定位与无损采摘入盆任务，构建了基于 **睿尔曼 RM65-BI 6自由度协作机械臂**、**Intel RealSense D435 深度相机** 以及 **ROS 2 Jazzy / MoveIt 2** 的一体化自主抓取与控制平台。

---

## 硬件与系统架构

- **机械臂本体**：睿尔曼 RM65-BI（6-DoF 超轻量协作机械臂，Controller V1.7.1，Algorithm 1.5.5）
- **末端执行器**：RS485 Modbus-RTU 智能电动两指夹爪
- **视觉感知**：Intel RealSense D435 RGB-D 深度相机（手眼标定 Eye-to-Hand 架构）
- **计算主机**：Dell Vostro 3030 工控机（12th Gen Intel i5-12400 / 16GB RAM / 1TB NVMe SSD / Ubuntu 24.04 LTS）
- **开发控制端**：MacBook Pro（通过千兆网络 `10.77.0.1 <-> 10.77.0.2` 免密 SSH 联动调度）

---

## 软件运行栈

- **操作系统**：Ubuntu 24.04.5 LTS (Linux 7.0 generic)
- **机器人操作系统**：ROS 2 Jazzy Jalisco (`/opt/ros/jazzy`)
- **运动规划器**：MoveIt 2 完整栈（OMPL 运动学规划、碰撞检测与轨迹生成）
- **视觉算法**：YOLOv11 实例分割网络（实时推理帧率 ~27.5 FPS，AVX2 CPU 加速）
- **点云处理**：基于 RealSense 深度点云的球体几何拟合与果心空间 3D 定位

## 常用操作指令

```bash
# 1. 硬件通信与服务状态全面自检
./arm_ctl doctor

# 2. 启动视觉与机械臂驱动服务栈（目标果品支持 orange / apple）
./arm_ctl start --target orange

# 3. 查看实时识别状态与果实坐标
./arm_ctl status

# 4. 执行抓取入盆动作（preview 模式安全预演 / single 模式真机执行）
./arm_ctl grasp --mode preview
./arm_ctl grasp --mode single

# 5. 停止所有机器人服务
./arm_ctl stop
```
